Welcome to CBT Indolat V2, a computer-based testing (CBT) platform built to change the way you run exams, assessments and tryouts (practice exams). Our goal is simple: give you a tool that is powerful yet easy to use, whether you are a teacher, a tutoring centre owner, a certification body or an HR department.

<Info>
  **Our core value: free, forever.**

  We believe everyone deserves access to reliable exam technology. That's why we're proud to offer our **STANDARD Plan**: **200 free credits to start running exams, every month, forever.**

  This is not just a trial. You can use CBT Indolat's core features straight away and run exams for your first 50 participants every month, **at no extra cost**.
</Info>

<Note>
  The screenshots in this guide show the Indonesian interface. Menu and button names in the text use the English interface. To switch the admin panel to English, open the account menu at the bottom of the sidebar, click the row that shows the current language (for example **Bahasa Indonesia**) and choose **English**.
</Note>

## <Icon icon="book-open-lines" /> Who Is This Guide For?

CBT Indolat is used by teachers, schools, tutoring centres, training and certification bodies, competition committees and HR teams that need an online exam system.

You don't need any technical knowledge to get started. This documentation walks you through the whole process, from setting up to finishing an exam.

## 🧭 How Creating an Exam Works

In short, creating an exam in CBT Indolat looks like this:

**Plan the exam → Create the exam → Prepare the questions → Add participants → Set up sessions → Run the exam → Review the results**
