Welcome to CBT Indolat V2, a computer-based testing (CBT) platform built to change the way you run exams, assessments and tryouts (practice exams). Our goal is simple: give you a tool that is powerful yet easy to use, whether you are a teacher, a tutoring centre owner, a certification body or an HR department.

<Info>
  **Our core value: free, forever.**

  We believe everyone deserves access to reliable exam technology. That's why we're proud to offer our **Standard Plan**: **200 free exam credits every month, forever.**

  This is not just a trial. You can use CBT Indolat's core features straight away and run exams with up to **50 participants at once**, **at no extra cost**. One credit is used each time a participant starts a test.

  The 200-credit allowance applies once you complete the onboarding profile in the admin panel. While the profile is incomplete, the free allowance can be capped at 50 credits per month.
</Info>

  The screenshots in this guide show the Indonesian interface. </Note>

## <Icon icon="book-open-lines" /> Who Is This Guide For?

CBT Indolat is used by teachers, schools, tutoring centres, training and certification bodies, competition committees and HR teams that need an online exam system.

You don't need any technical knowledge to get started. This documentation walks you through the whole process, from setting up to finishing an exam.

## <Icon icon="grid-2" /> The New Layout: Portal and Modules

From **30 November 2026**, every admin uses the new layout. After signing in you land on the **Portal**, then choose the module to open:

- **Administrasi Aplikasi** (Application Administration) for users, admin team and roles, finance, subscription, project profile, branding, domains, and API integration.
- **Platform Ujian (CBT)** (Exam Platform) for question packages, exams, sessions, monitoring, results, and certificates.
- **Learning Management System (LMS)** for classes, teaching schedules, and learning.
- **Pembuat Website** (Website Builder) for your institution's website.

Several menus that used to sit in the CBT sidebar have moved to **Administrasi Aplikasi**. The full list is in [Getting to Know the Portal and Modules](/en/memulai/mengenal-portal-dan-modul#changes-from-the-old-layout).

## <Icon icon="route" /> How Creating an Exam Works

In short, creating an exam in CBT Indolat looks like this:

**Sign in to the Portal → Open Platform Ujian (CBT) → Prepare the question package → Create the exam and its tests → Set up sessions → Add participants → Run the exam → Review the results**
