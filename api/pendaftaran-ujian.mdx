## Endpoint pendaftaran

<Accordion title="GET /exams/{exam}/participants — Daftar peserta terdaftar">
  ### Parameter

  | Nama | Lokasi | Wajib | Tipe | Keterangan |
  | --- | --- | --: | --- | --- |
  | `exam` | Path | Ya | integer | ID ujian. |
  | `status` | Query | Tidak | integer | Status pendaftaran: `0` perlu diverifikasi, `1` aktif, `2` ditangguhkan, `3` perlu ditinjau, `4` selesai. |
  | `search` | Query | Tidak | string | Mencari kode peserta atau nama peserta. |
  | `page` | Query | Tidak | integer | Nomor halaman. Default `1`. |
  | `per_page` | Query | Tidak | integer | Data per halaman, `1–100`. Default `25`. |

<Accordion title="POST /exams/{exam}/participants — Mendaftarkan peserta ke ujian">
  Request ini aman untuk diulang. Peserta yang sudah terdaftar tidak didaftarkan dua kali, tetapi dilaporkan pada `already_registered`. Setiap pendaftaran baru mengirim webhook `exam_participant.registered`.

  Saat peserta didaftarkan:

  - Peserta mendapat kode peserta (`participant_code`) dan satu data hasil untuk setiap tes dalam ujian.
  - Pada ujian berjenjang, hanya tes pada jenjang pertama yang langsung aktif. Tes pada jenjang berikutnya terbuka setelah jenjang sebelumnya selesai.
  - Jika ujian memakai pembagian sesi otomatis (`is_auto_assign_session: true`), peserta ditempatkan pada sesi yang paling awal dibuat untuk setiap tes. Jika tidak, admin perlu menempatkan peserta ke sesi melalui panel sebelum peserta dapat mengerjakan tes. Sampai saat itu, link akses melaporkan `locked_reason: "no_session"`.

  Ujian yang sudah dikunci (`is_locked: true`) menolak pendaftaran dengan status `409`. ID peserta yang tidak ditemukan pada projek dilaporkan pada `rejected`, misalnya `{ "participant_id": 999, "reason": "Peserta tidak ditemukan pada projek ini." }`.

  ### Parameter

  | Nama | Lokasi | Wajib | Tipe | Keterangan |
  | --- | --- | --: | --- | --- |
  | `exam` | Path | Ya | integer | ID ujian. |
  | `participant_ids` | Body | Ya | integer\[\] | Berisi 1–500 ID peserta. |
  | `participant_ids.*` | Body | Ya | integer | ID peserta. |

  ### Contoh request

  ```bash
  curl -X POST "https://app.indolat.com/api/v1/exams/12/participants" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json" \
    -H "Content-Type: application/json" \
    -d '{ "participant_ids": [340, 341, 342] }'
  ```

<Accordion title="DELETE /exams/{exam}/participants/{participant} — Membatalkan pendaftaran">
  Permintaan ditolak dengan status `409` apabila peserta sudah menyelesaikan salah satu tes atau sudah memiliki nilai pada ujian ini. Pembatalan menghapus kode peserta beserta seluruh data tes peserta pada ujian tersebut, lalu mengirim webhook `exam_participant.unregistered`.

  ### Parameter

  | Nama | Lokasi | Wajib | Tipe | Keterangan |
  | --- | --- | --: | --- | --- |
  | `exam` | Path | Ya | integer | ID ujian. |
  | `participant` | Path | Ya | integer | ID peserta. |

  ### Contoh request

  ```bash
  curl -X DELETE "https://app.indolat.com/api/v1/exams/12/participants/340" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json"
  ```

  ### Contoh response

  ```json
  {
    "success": true,
    "message": "Pendaftaran peserta pada ujian berhasil dibatalkan.",
    "data": null
  }
  ```
</Accordion>

<Accordion title="POST /exams/{exam}/participants/{participant}/access-links — Membuat link akses ujian">
  Menghasilkan satu link untuk setiap tes dalam ujian. Link tersebut membuat peserta langsung masuk tanpa mengetik kata sandi, lalu membuka halaman persiapan tes.

  Perilaku link:

  - **Setiap link hanya dapat dipakai satu kali**, dan harus dipakai sebelum `expires_at`. Masa berlaku default 1.440 menit (24 jam), maksimal 10.080 menit (7 hari). Link yang sudah dipakai atau sudah kedaluwarsa menampilkan pesan bahwa link tidak berlaku lagi.
  - Jika peserta perlu masuk kembali, misalnya setelah menutup tab, berpindah perangkat, atau koneksi terputus, buat link baru. Link baru untuk tes yang sedang dikerjakan melanjutkan pengerjaan yang sama, bukan memulai ulang.
  - Link yang dibuat sebelumnya tetap berlaku sampai dipakai atau kedaluwarsa.
  - `exam_url` tetap dikembalikan walaupun tes belum dapat dikerjakan. Periksa `can_start` sebelum mengarahkan peserta. Link untuk tes dengan `can_start: false` tidak membuka tes; peserta diarahkan ke dashboard CBT atau mendapat halaman tidak ditemukan.
  - Satu peserta hanya dapat memiliki satu sesi login aktif. Membuka link di perangkat lain mengakhiri sesi di perangkat sebelumnya.
  - Peserta nonaktif tidak dapat masuk melalui link. Link tetap dibuat, dan `message` pada respons menjelaskan bahwa peserta sedang nonaktif.

  <Tip>
    Link akses dirancang untuk alur redirect dari aplikasi Anda, misalnya tombol "Mulai Ujian". Buat link tepat saat peserta menekan tombol dengan `expires_in_minutes` yang singkat (misalnya 5–15 menit), lalu langsung redirect peserta. Jangan menyimpan link atau mengirimkannya melalui email atau chat: beberapa aplikasi chat dan email membuka link secara otomatis untuk pratinjau, sehingga link sudah terpakai sebelum peserta mengkliknya.
  </Tip>

  ### Parameter

  | Nama | Lokasi | Wajib | Tipe | Keterangan |
  | --- | --- | --: | --- | --- |
  | `exam` | Path | Ya | integer | ID ujian. |
  | `participant` | Path | Ya | integer | ID peserta yang telah terdaftar. |
  | `expires_in_minutes` | Body | Tidak | integer | Masa berlaku link, `1–10080`. Default `1440`. |

  ### Field respons per link

  | Field | Keterangan |
  | --- | --- |
  | `exam_quiz_id`, `exam_quiz_name` | Tes yang dibuka oleh link. |
  | `user_result_exam_uuid` | ID pengerjaan tes peserta, sama dengan `uuid` pada API Hasil Ujian. |
  | `status` | Status hasil tes: `0` pending, `1` aktif, `2` selesai, `3` ditolak. |
  | `progress` | `not_started`, `in_progress`, atau `finished`. |
  | `has_session` | `true` jika peserta sudah ditempatkan pada sesi. |
  | `session` | Jadwal sesi (`start_at`, `end_at`), atau `null` jika belum ada sesi. |
  | `can_start` | `true` jika peserta dapat memulai atau melanjutkan tes ini sekarang. |
  | `locked_reason` | Penyebab tes belum dapat dikerjakan, atau `null` jika `can_start` bernilai `true`. |
  | `exam_url` | Link akses tes. |
  | `expires_at` | Waktu kedaluwarsa link. |

  Nilai `locked_reason`:

  - `finished` — tes sudah selesai dikerjakan.
  - `unavailable` — ujian di luar jadwal atau diarsipkan, pendaftaran peserta ditangguhkan atau sudah selesai, atau tes ditolak.
  - `payment` — tes menunggu pembayaran.
  - `pending` — jenjang tes belum terbuka, atau pendaftaran masih menunggu verifikasi.
  - `order` — tes harus dikerjakan berurutan dan tes sebelumnya belum selesai.
  - `no_session` — peserta belum ditempatkan pada sesi, atau sesinya belum memiliki paket soal.
  - `no_questions` — paket soal pada sesi belum berisi soal.
  - `outside_session` — waktu saat ini berada di luar jadwal sesi.

  Status `404` dikembalikan jika ujian atau peserta tidak ditemukan, atau peserta belum terdaftar pada ujian. Status `422` dikembalikan jika ujian belum memiliki tes.

  ### Contoh request

  ```bash
  curl -X POST "https://app.indolat.com/api/v1/exams/12/participants/340/access-links" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json" \
    -H "Content-Type: application/json" \
    -d '{ "expires_in_minutes": 10 }'
  ```
