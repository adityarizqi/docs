Seluruh request pada halaman ini membutuhkan [Bearer API Key](/api/autentikasi).

Satu hasil ujian mewakili satu tes milik satu peserta. Data hasil dibuat saat peserta didaftarkan ke ujian, lalu diperbarui saat peserta mengerjakan tes dan saat nilainya dihitung. Hasil milik peserta yang sudah dihapus dari projek tidak ditampilkan.

## Kapan nilai tersedia

`score` bernilai `null` sampai nilai tes dihitung. Waktu perhitungannya bergantung pada metode penilaian tes:

| Metode penilaian | Kapan `score` terisi |
| --- | --- |
| Perhitungan Skor Soal (Akumulasi Benar/Salah) | Otomatis saat peserta selesai mengerjakan tes. |
| Perhitungan Skor Jawaban (Akumulasi Skor Jawaban) | Otomatis saat peserta selesai mengerjakan tes. |
| Psikotes (Pengelompokan Jawaban) | Otomatis saat peserta selesai. `score` selalu `0` dan tes ini tidak ikut dihitung dalam nilai akhir ujian; hasil per kelompok jawaban tidak tersedia melalui API. |
| IRT (Referensi UTBK 0-1000, TKA SMA/SMK 200-800, TKA SD/SMP 0-100) | Setelah admin menjalankan **Hitung Skor** → **Perhitungan IRT** pada panel. Sebelum itu `score` bernilai `null`. |
| Penilaian Manual | Setelah admin menilai jawaban peserta pada panel. |

Nilai dapat berubah setelah pertama kali terbit, misalnya saat admin menjalankan ulang **Perhitungan IRT** atau perhitungan ulang skor. Setiap perubahan memperbarui `updated_at` dan mengirim webhook `exam_result.scored`. Gunakan `updated_since` untuk menyinkronkan ulang hasil yang berubah.

### Struktur `meta_score`

`meta_score` bernilai `null` sebelum nilai pertama kali dihitung. Isinya bergantung pada metode penilaian:

| Metode penilaian | Isi `meta_score` |
| --- | --- |
| Akumulasi Benar/Salah | `correct`, `incorrect`, `unanswered` (jumlah soal). |
| Akumulasi Skor Jawaban | `correct`, `incorrect`, `unanswered`, dan `answer_scores` berupa objek `{ "<id soal>": skor }`. |
| Psikotes | `total_answered`, `total_unanswered`. |
| IRT | `correct`, `incorrect`, `unanswered`, `irt_theta` (kemampuan peserta), `irt_scale` (skala yang dipakai: `irt`, `irt_tka_sma`, atau `irt_tka_sd_smp`), dan `difficulty_map` berupa objek `{ "<id soal>": tingkat kesulitan }`. |

## Endpoint hasil ujian

<Accordion title="GET /exam-results — Daftar hasil ujian">
  Data diurutkan dari hasil terbaru.

  ### Parameter

  | Nama | Lokasi | Wajib | Tipe | Keterangan |
  | --- | --- | --: | --- | --- |
  | `exam_id` | Query | Tidak | integer | Filter ID ujian. |
  | `participant_id` | Query | Tidak | integer | Filter ID peserta. |
  | `email` | Query | Tidak | email | Filter email peserta secara persis. |
  | `exam_quiz_id` | Query | Tidak | integer | Filter ID tes. |
  | `status` | Query | Tidak | integer | `0` pending, `1` aktif (belum atau sedang dikerjakan), `2` selesai, `3` ditolak. |
  | `min_score` | Query | Tidak | numeric | Nilai minimum. |
  | `max_score` | Query | Tidak | numeric | Nilai maksimum. |
  | `finished_from` | Query | Tidak | datetime | Waktu selesai minimum dalam ISO 8601 dan harus di-URL-encode. |
  | `finished_until` | Query | Tidak | datetime | Waktu selesai maksimum dalam ISO 8601 dan harus di-URL-encode. |
  | `updated_since` | Query | Tidak | datetime | Hanya hasil yang berubah sejak waktu ini; ISO 8601 dan harus di-URL-encode. |
  | `page` | Query | Tidak | integer | Nomor halaman. Default `1`. |
  | `per_page` | Query | Tidak | integer | Data per halaman, `1–100`. Default `25`. |

  ### Contoh request

  ```bash
  curl -X GET "https://app.indolat.com/api/v1/exam-results?exam_id=12&status=2&min_score=70&page=1&per_page=25" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json"
  ```
