Seluruh request pada halaman ini membutuhkan [Bearer API Key](/api/autentikasi).

## Endpoint hasil ujian

<Accordion title="GET /exam-results — Daftar hasil ujian">
  ### Parameter

  | Nama | Lokasi | Wajib | Tipe | Keterangan |
  | --- | --- | --: | --- | --- |
  | `exam_id` | Query | Tidak | integer | Filter ID ujian. |
  | `participant_id` | Query | Tidak | integer | Filter ID peserta. |
  | `email` | Query | Tidak | email | Filter email peserta secara persis. |
  | `exam_quiz_id` | Query | Tidak | integer | Filter ID tes. |
  | `status` | Query | Tidak | integer | `0` pending, `1` aktif, `2` selesai, `3` ditolak. |
  | `min_score` | Query | Tidak | numeric | Nilai minimum. |
  | `max_score` | Query | Tidak | numeric | Nilai maksimum. |
  | `finished_from` | Query | Tidak | datetime | Waktu selesai minimum dalam ISO 8601 dan harus di-URL-encode. |
  | `finished_until` | Query | Tidak | datetime | Waktu selesai maksimum dalam ISO 8601 dan harus di-URL-encode. |
  | `updated_since` | Query | Tidak | datetime | Hanya hasil yang berubah sejak waktu ini; ISO 8601 dan harus di-URL-encode. |
  | `page` | Query | Tidak | integer | Nomor halaman. Default `1`. |
  | `per_page` | Query | Tidak | integer | Data per halaman, `1–100`. Default `25`. |

  ### Contoh request

  ```bash
  curl -X GET "https://app.indolat.com/api/v1/exam-results?exam_id=12&status=2&min_score=70&page=1&per_page=25" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json"
  ```
